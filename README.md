# האתר של תומר בן דוד — tomerbendavid.co.il

אתר סטטי (HTML/CSS/JS בלבד) — אין תלות בשום פלטפורמה. אפשר להעלות אותו לכל שרת אחסון.

**כתובת זמנית לצפייה:** https://avgilx.github.io/tomer-bendavid-site/

## מבנה האתר

```
דף הבית (index.html)
├── לאנשים פרטיים (individuals.html)
│   ├── אימון אישי .................. personal-training.html
│   ├── ריטריטים .................... retreats.html
│   ├── לימודי קונג פו בפגודה ....... kung-fu.html
│   └── הכשרת מורים ומנחים .......... teacher-training.html
├── לארגונים וצוותים (organizations.html)
│   ├── כשעסקים וקונג פו נפגשים ..... kungfu-business.html
│   ├── סדנת יין־יאנג ............... yin-yang.html
│   ├── סדנאות בהתאמה אישית ......... custom-workshops.html
│   └── ליווי אישי למנהלים .......... executive-coaching.html
├── תומר (about.html)
└── צור קשר (contact.html)
```

כל תחום הוא **דף מוצר נפרד** — לא כרטיס בתוך דף אחד. בסוף כל דף יש פס יצירת קשר
(טלפון, וואטסאפ, מייל + כפתור לטופס), כדי שתמיד תהיה דרך ליצור קשר תוך כדי עיון במוצרים.

| קובץ | מה זה |
|---|---|
| `css/style.css` | כל העיצוב |
| `js/main.js` | תפריט נייד + אנימציות גלילה |
| `js/contact.js` | לשוניות הטופס ושליחה בוואטסאפ |
| `assets/img/` | תמונות, סימן הגג של הפגודה (`mark.png`) ואייקונים |
| `../build_site.py` | מחולל הדפים — משמש רק לשינויי מבנה, לא נדרש לעריכת טקסט |

## עדכון טקסטים

כל הטקסטים נמצאים ישירות בקובצי ה־HTML — פותחים בכל עורך טקסט, מחפשים את המשפט ומחליפים.
מספר הטלפון והמייל מופיעים בכל הדפים; אם משתנים, לחפש `972527000030` ו־`tomer@orin.co.il`
ולהחליף בכל הקבצים.

אם משנים **מבנה** (מוסיפים דף מוצר, משנים תפריט) — עורכים את `build_site.py` ומריצים
`python3 build_site.py` מתיקיית הפרויקט. שימו לב: הרצה מחדש דורסת את קובצי ה-HTML,
אז אם ערכתם טקסט ישירות בקבצים — להעביר אותו קודם לסקריפט.

## העלאה לדומיין (בסוף העבודה)

1. להעלות את כל תוכן התיקייה הזו לתיקיית השורש של האחסון (בדרך כלל `public_html`).
2. לוודא שהדומיין tomerbendavid.co.il מפנה לשרת. הדומיין והאחסון נרכשו בעבר אצל דודי.
3. להפעיל HTTPS (באחסון ישראלי בדרך כלל Let's Encrypt בלחיצה).

- **תמונות** — תומר ביקש להחליף את תמונת המדבר שבה הוא יושב, ולהשתמש בתמונת הפרופיל
  שלו מוואטסאפ (+ עוד תמונה שלו יושב). כרגע מוצגות תמונות מהאתר הקודם.
- **טקסטים** — תומר שולח נוסח חדש לפסקת הפתיחה בדף הבית ולעמוד "תומר".
- **שעות הקבוצות** — בדף הפגודה מופיע לוח זמנים אחר (ילדים ברביעי 17:00–18:30,
  קונג פו שני/רביעי 20:00–21:30). באתר מופיעות השעות מהמסמך של תומר. צריך לאשר מה נכון.
- **לוגו** — כרגע סימן הגג של הפגודה בלי הכיתוב, לפי הצעתו. קל להסיר או להחליף.
- **ניסוח "לבונה"** — מקושר ל-levona.co.il. לאשר את הניסוח המדויק.
- **תאריך פרסום הכתבה** — האתר צריך לעלות לפני.
- **הונג גאר / בלוג ותקשורת** — היו באתר הקודם; תומר הזכיר אותם כאפשרות, טרם הוחלט.
